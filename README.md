# ⚛️ Quantum Random Number Generator (QRNG)

A **Quantum Random Number Generator (QRNG)** built using **Qiskit**, leveraging true quantum randomness generated by qubit superposition and measurement.  
This project explores how quantum randomness can be applied in real-world systems such as:

- 🔐 **Password Generation**
- 🎨 **Random Color & Palette Generation**
- 🧩 **Cryptographic Key Generation**
- 📊 **Statistical Randomness Analysis**

---

## 📁 Project Overview

This project uses the **Qiskit Aer Simulator** to generate quantum measurement outcomes from superposed qubits.  
The randomness obtained from these measurements is analyzed, visualized, and applied to different use cases.

### 🧩 Modules Implemented:
| Module | Description |
|--------|--------------|
| **QRNG Core** | Generates quantum random numbers using Qiskit. |
| **Password Generator** | Creates strong, random passwords using quantum bits. |
| **Color & Palette Generator** | Produces random RGB/HEX colors for design and UI usage. |
| **Cryptographic Key Generator** | Generates secure random keys for encryption use cases. |
| **Distribution Analysis** | Performs statistical validation of randomness (mean, std dev, chi-squared, etc.). |

---

## 🚀 Features

- ✅ True quantum randomness using simulated qubits  
- ✅ Customizable number of qubits and measurement shots  
- ✅ Visualization of random distributions using Matplotlib / Qiskit’s `plot_histogram`  
- ✅ Integrated password, color, and key generators  
- ✅ Statistical analysis (uniformity check, standard deviation, chi-squared test)
